# Listas M3U (Android TV)

App para la tele que abre **tus propias** listas M3U / M3U8 y reproduce sus canales.
No trae listas incluidas y no reproduce contenido protegido (DRM).

## Qué hace
- Agregar listas por dirección (URL) o desde un archivo (si la tele tiene explorador de archivos).
- Guarda las listas; las que son por URL se actualizan cada vez que se abren.
- Muestra los grupos (`group-title`) y logos (`tvg-logo`) de la lista, con buscador y favoritos.
- Reproductor a pantalla completa (HLS, DASH, TS, MP4). Al abrir la app vuelve al último canal.

## Control remoto
- En un canal: ▲▼ o Canal+/Canal− cambian de canal, OK o ◀ abre la lista lateral, Atrás vuelve a los canales.
- En la lista de canales: mantener OK sobre un canal lo marca como favorito.
- En "Mis listas": mantener OK sobre una lista la borra.

## Instalar en la tele
GitHub Actions arma el APK en cada cambio. En la tele, con la app **Downloader**, abrir:

https://github.com/luchoproducciones/tvprueba/releases/download/listas-ultima/ListasM3U.apk
